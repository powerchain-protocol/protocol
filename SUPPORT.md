# PowerChain Support

## Usage and development questions

Use repository discussions or the appropriate issue template for reproducible development questions, documentation gaps, and feature requests.

Include:

- PowerChain version
- Operating system and runtime versions
- A minimal reproduction
- Expected and actual behavior
- Relevant logs with secrets removed

## Bugs

Open a bug report only after checking existing issues. Do not use public issues for vulnerabilities or sensitive production incidents.

## Security

Report vulnerabilities privately according to [SECURITY.md](./SECURITY.md).

## Operational incidents

For production incidents, preserve evidence, rotate exposed credentials, disable compromised integrations, and follow your organization’s incident-response process before sharing sanitized diagnostics.

PowerChain beta software is provided without guaranteed response times or service-level commitments.
