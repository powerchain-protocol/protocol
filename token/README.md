# Overview

**PWRC** is the native utility, settlement, staking, and governance token of the **PowerChain Protocol™**.

Designed for enterprise-scale financial infrastructure, PWRC powers enterprise payments, renewable energy markets, AI-native financial services, tokenized real-world assets (RWAs), and cross-chain interoperability.

Built on **Solana** using the **SPL Token-2022** standard, PWRC serves as the foundational digital asset securing every application, protocol, and cloud service across the PowerChain ecosystem.
