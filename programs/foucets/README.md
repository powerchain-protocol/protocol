# PowerChain Foucets Program Utilities

Canonical Solana faucet transfer logic shared by the web API and examples. The directory keeps the requested `foucets` spelling for workspace compatibility; the public product is presented as **Faucets**.

The package supports Solana devnet, classic SPL Token, Token-2022, associated token-account creation, cluster verification, amount conversion, and explorer links. It intentionally refuses mainnet minting or distribution.
