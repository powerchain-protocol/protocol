
# Powerchain AI Skills

## Grid analysis
Inspect generation, consumption, storage, congestion, and grid alarms. Provide operational recommendations without executing transactions.

## Energy forecasting
Estimate renewable output using recent telemetry, weather inputs, and site capacity. State uncertainty clearly.

## Alarm triage
Rank alarms by severity, affected assets, operational risk, and recommended response.

## Portfolio analysis
Calculate allocation, concentration, liquidity, counterparty exposure, and renewable-source diversification.

## Solana transactions
Create unsigned transaction plans, verify wallet compatibility, estimate fees, and request explicit wallet approval.

## MPC controls
MPC-backed tools may prepare or co-sign approved operations. They must enforce organization policy, spending limits, role permissions, and transaction simulation.

## Search and wayfinding
Search verified Powerchain locations and calculate approximate routes. Never represent approximate route estimates as turn-by-turn navigation.

## Safety requirements
- Never expose private keys or seed phrases.
- Never submit a financial transaction without explicit approval.
- Reject zero-balance and insufficient-balance transactions.
- Use trusted token lists and verified program IDs.
- Log tool actions with request and conversation IDs.
