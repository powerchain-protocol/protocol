# Powerchain Platform V3

A visually polished, responsive Next.js 15 platform site with product and service routes.

## Highlights
- Centered “Trusted infrastructure partners” section with real brand icons via `react-icons`
- Professional CSS 3D globe and world-map network treatment
- Header navigation with Home, About, Products dropdown, Services dropdown, and icons
- Product pages for tokenization, marketplace, carbon, payments, swap, bridge, store, mobile, OS, and IoT
- Service pages with reusable data-driven rendering
- Light/dark/system theme provider and theme toggle
- Wallet provider, connect-wallet modal, and Sonner toast
- Requested `/data`, `/lib`, `/types`, `/utils`, and component folders
- Logo-based favicon
- Responsive mobile navigation

## Run
```bash
npm install
npm run dev
```

## Validate
```bash
npm run typecheck
npm run build
```
