
# @powerchain/renewables

Domain package for renewable assets, generation, impact, pools, solar panel rentals, metering and PWRC token use cases.

## Core functions

- `summarizeRenewables`
- `calculatePoolMetrics`
- `contributeToPool`
- `calculateRentalQuote`
- `renewableTokenUseCases`

Mock and devnet values must be labelled. Mainnet asset, token and market data must remain unavailable unless live sources are configured.
