
# Powerchain packages

Domain packages are framework-neutral and shared across web, dashboard, backend, merchant, and checkout applications.

Core domains:

- `@powerchain/marketplace`
- `@powerchain/renewables`
- `@powerchain/payments`
- `@powerchain/wallet`
- `@powerchain/ai`
- `@powerchain/blockchain`
- `@powerchain/checkout`
- `@powerchain/checkout-react`
- `@powerchain/openapi-client`

Use `workspace:*` for internal dependencies. Public packages publish through the beta and stable release scripts.
