# Glossary

| Term | Meaning |
|---|---|
| DER | Distributed energy resource, such as rooftop solar, batteries, or controllable demand. |
| EAC | Energy attribute certificate representing environmental attributes of generated electricity. |
| GO | Guarantee of Origin. |
| PoG | Proof of Generation, PowerChain's proposed verification process for renewable-generation events. |
| PVM | PowerChain Virtual Machine, the project's execution-layer architecture. |
| REC | Renewable Energy Certificate. |
| RWA | Real-world asset represented or referenced by a digital record or token. |
| SCADA | Supervisory control and data acquisition. |
| SVM | Solana Virtual Machine execution model. |
| VPP | Virtual power plant coordinating distributed resources. |
