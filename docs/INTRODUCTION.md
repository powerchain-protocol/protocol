# Introduction

PowerChain is an open protocol and application platform for verifiable renewable-energy data, programmable settlement, tokenized infrastructure, and interoperable digital energy markets.

The repository combines web applications, backend services, shared schemas, SDKs, Solana/SVM programs, Sui packages, energy-IoT modules, and operational documentation. The current release is `1.0.0-beta.1`; beta status means interfaces and deployment assumptions can change before a stable release.

## Documentation map

- Architecture explains execution, networking, data, and integration boundaries.
- Protocols define energy, carbon, RWA, oracle, treasury, identity, governance, AI, and cross-chain behaviour.
- Developer documentation covers APIs, SDKs, programs, testing, local development, and deployment.
- Enterprise documentation covers administration, marketplace, analytics, CRM, ERP, and compliance-oriented workflows.
