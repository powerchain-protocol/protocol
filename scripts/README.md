
# Repository scripts

- `clean-install.mjs` performs a clean pnpm installation.
- `optimize-assets.mjs` produces optimized public WebP assets.
- `sync-program-id.ts` synchronizes the Anchor and TypeScript program IDs.
- `validate-public-assets.mjs` checks required icons and screenshots.
- `migrate-content.mjs` migrates legacy public assets into the optimized directory structure.
